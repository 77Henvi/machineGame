เกม Turn-based Fighter
คำอธิบายเกม : Turn-based Fighter ต่อสู้กับบอท โดยใช้การโพสท่าผ่านกล้องเพื่อออกท่าในเกม
Pain Point : แก้ปวดเมื่อยจากการทำงานหน้าคอม
ระบบเกม : Turn-based 2D
	-เล่นกับBot
	-มีท่าให้ออก3ท่าพื้นฐาน
	-มี Quick-Time Event
	-มีหลอดเลือดMax100
	-1Turn 5วิ 
ท่าที่มี:
1.โจมตี(ทำได้20ดาเมจ)
2.ป้องกัน
  2.1ป้องกันปกติ(ป้องกันได้10ดาเมจ)
  2.2ป้องกันและสวน(สวนได้30ดาเมจ)
      กดได้เมื่อเกิด Quick Time Event
3.ท่าไม้ตาย(ทำได้50ดาเมจ)
  ได้จากการโจมตีและป้องกัน โดยจะได้เกตมารอละ1ครบ4แล้วจะกดได้
Quick Time Event: ให้เวลากด3วิ
  สุ่มเกิดจากท่าโจมตีศัตรู มีโอกาศ20%ต่อการโจมตี
   - ป้องกันได้ จะได้ท่าสวน
   - ป้องกันไม่ได้(โดนดาเมจ2เท่าของดาเมจศัตรู)

Map:เมื่ออ่านTutorialเสร็จนอกจากจะกดเลือดตัวละครแล้วจะใส่กดเลือกชุดด่านโดยจะมีชุดด่านForest(Easy),Graveyard(Normal),Vamprie_Castle(Hard)และ Secrets_Map(มีให้กดก็ต่อเมื่อชนะครบทุกความยาก) แต่ละด่านจะมี4ห้อง มีมอนเตอร์เป็นของตัวเอง และมีบอสเป็นตัวสุดท้าย
    -เมื่อเล่นผ่านตัวเราจะวิ่งผ่านมอนเตอร์ที่ตายเพื่อไปอีกด่าน
    -เมื่อเล่นผ่านแต่ละด่านจะได้เลือดสูงสุดเพิ่ม10และฮิลเลือดตัวละครเราจนเต็ม

Bot: ออกท่าได้เหมือนผู้เล่น ยกเว้นป้องกันกับท่าไม้ตาย
 - ด่าน Forest จะมี Slime(เลือด50,โจมตี5),Werewolf(เลือด100,โจมตี10),Satyr(เลือด50,โจมตี15 2ครั้งต่อเทิร์น) และ Minotaur(Boss)(เลือด150,โจมตี30แต่โจมตีทุกๆ2เทิร์น)
 - ด่าน Graveyard จะมี  Zombie(เลือด70,โจมตี10),Skeleton(เลือด100,โจมตี15),Yurei(เลือด90,โจมตี15แบบป้องกันไม่ได้)และ Gorgon(Boss)(เลือด200,โจมตี15ในเฟสเเรก และ30ในเฟสที่2)
 - ด่าน Vamprie_Castle จะมี Skeleton(เลือด100,โจมตี10),Vampire(เลือด120,โจมตี5ถ้าตีเข้าHPผู้เล่นจะฟื้นฟูเลือด5),Vampire_Duke(เลือด150,โจมตี15ถ้าโจมตีโดนผู้เล่นจะฟื้นฟูเลือด5),Vampire_Queen(Boss)(เลือด200,มีท่าโจมตี2ท่า1.โจมตีทำดาเมจ20 1ครั้ง และ 10 1ครั้ง ถ้าตีเข้าHPเล่นจะฟื้นฟูเลือด10ต่อครั้งที่,2.ร่ายดีบัพใส่ผู้เล่น2เทิร์นทำให้สร้างดาเมจลดลง10และ5ตามลำดับ และเมื่อหายไปจะฟื้นฟูผู้เล่น10(CD3เทิร์น))
Note : ถ้าศัตรูมีการโจมตี2ครั้งสามารถสุ่มเกิดQuick Time Event ได้ทั้ง2ครั้ง
              Gorgon(Boss) จะเปลี่ยนเฟสตอนเลือดเหลือ100หรือน้อยกว่า
              CD = CoolDown ของความสามารถมีแค่Vampire_Queen(Boss)ที่มี
              ด่านSecrets_Mapจะไม่มีอยู่จริงมันมีแค่ชื่อ

รางวัล:เมื่อชนะบอสในชุดด่านนั้นๆจะได้เหรียญตราของชุดด่านนั้นๆ
